# Character Asset Studio 运营手册

更新日期：2026-10-04。适用角色：角色创作者、发布运营。
入口：`/admin/characters/{characterId}?tab=assets`。
权威：[角色素材 ADR](../architecture/16-character-asset-studio-authority.md)；范围与实际限制：[当前覆盖](CURRENT_FUNCTIONAL_COVERAGE.md)；验收：[体检清单](ADMIN_PRODUCT_HEALTH_CHECKLIST.md)。

## 创作与发布

| 职责 | 流程与完成结果 |
| --- | --- |
| 角色创作 | 创建/修订内容 → 建立身份和参考集 → 生成或上传图片 → 维护合格角色图片库 → 交接明确内容/身份版本、可用图片与待修复项 |
| 发布运营 | 读取交接 → 为三个产品槽位选择不同图片 → 准备不可变候选 → 真实预览与自动技术检查 → 显式发布 → 核对用户消费版本 |

两种职责可由同一有权限人员承担，但写权限和生效时点分开。交接不创建 Release、不切线上版本；需要改设定或新图时返回创作。日常不填写人工评分、逐图批准或五轮 QA；成年硬边界、基础拦截、文件/归属/来源检查及举报申诉继续有效。

## 创建、身份与交接

1. 填写成年角色资料、外观、人格、声音和开场，创建私有草稿；修改形成新内容版本，已发布快照保留。
2. 无身份时生成一张首肖像，或使用合法已有身份图。bootstrap 不声称使用了尚不存在的身份参考。
3. 「设为角色身份」原子固定图片来源、视觉身份和参考集，同时记录草稿主图；不发布，也不授予线上槽位。身份与来源必须属于该角色。
4. 身份建立后，生成默认使用明确身份、完整参考集和有资格的路线；基础参数、默认 brief 与客户语境让创作人员无需选择模型路径。高级设定与技术来源按需展开。
5. 交接指定采用的内容、身份、参考集和图库版本，说明可选择图片、失败与未知项。后续修改不得冒充原交接；没有独立交接入口时，不能用发布动作代替。

参考集更新需匹配观察到的 active revision；冲突后读取当前版本，不能覆盖他人的新参考集。路线不支持完整参考或 source variation 时明确阻断，不能静默丢参考；「更多类似」需同时支持来源图与角色参考的实际能力。

## 图片库与槽位选择

生成和上传的同角色图片先入图片库，通过文件可用性、归属、真实来源及基础检查后可选择。上传保留上传证据，生成保留原 Run/Item/Job/Attempt 与参数；不得用当前模型或新槽位名称改写历史来源。默认创作用途只是构图起点，合格图片可选择到任一合适槽位。

- 肖像：脸部与身份清楚，用于发现卡片/头像。
- 详情大图：人物与场景传达人格和氛围。
- 聊天图片：符合角色开场语境，自然且身份连续。

三个槽位必须用三张不同图片。采用只更新带版本的草稿，不影响线上，也不复制素材或重新生成。候选发布版本存在时先继续发布或放弃候选，再改草稿。

库中可搜索、看历史、维护标签与描述。归档、改私有或删除前检查所有身份/参考集、草稿、Look、Release、Run、投放/Campaign 等依赖；先在所属对象解除或替换依赖，批量全部成功或全部拒绝。复制角色需独立私有图片和文件，不继承公开资格或因源图片撤下而损坏。

## 失败与恢复

生成中保留同一请求，等待 GPU 与实际执行分别计时；刷新不发新生成。失败保留已交付素材与来源，只对明确合格的失败重试；unknown 先恢复/核对，不能连续新建请求。自动超时失败但未实际退款，之后收到原任务有效产物时，可通过恢复入口采用原产物并保留失败记录；已实际退款或由运营确认失败的任务不自动改成功。费用见 [经济契约](ECONOMY_AND_PRICING.md)。

写入前保存原 intent/key；断网、刷新或另一个 tab 使用同一精确请求恢复。已接纳但界面未变时核对 command 与投影；401/403 不算终态。超过安全恢复期限仍未知时显式 reconcile，不无限自动重放。只有精确内容/身份/参考集/槽位与资产读回一致才解锁；不以相似图片或其它角色回执代替。

## 预览、发布与退出

预览使用 Main 的真实发现卡片、详情、开场与聊天图片，并明确草稿/线上版本。缺失、重复、不可用或来源漂移的槽位不能用肖像代替；修正后重新预览。

准备发布冻结内容、身份、参考集、三槽位及各自来源，自动检查形成不可变候选。点击发布再次核验当前资格与真实 provider 来源，全部通过才原子更新 Release/Serving 与素材可见性；准备、校验成功不等于上线。任何槽位失败不留下部分线上副作用。发布失败先核对原 command，允许继续原发布或放弃候选后重建。

成功后核对工作区回执、Main 发现/详情/新会话、素材来源与账目；已有会话保持原 pin。暂停、恢复、回滚或 Serving 版本变化会永久撤销旧 live-preview token，即使恢复原 Release 也须重新打开。校验/监测政策更新时重新检查当前线上版本，旧通过记录不豁免新的来源与可用性规则。

- 草稿可归档并恢复为草稿，保留设定与素材。
- 暂停角色可直接退出运营，无需先恢复上线。
- 已上线版本通过暂停、恢复、回滚或退出命令处理，历史快照不可改写。

## 视频、声音与运营效果

视频从明确选择的合法角色图片开始，仅在 capability、workflow/profile、环境、权益和报价允许时执行；显示真实阶段，刷新仍看原任务，文件可用并交付后可播放。技术交付不证明身份连续性或容量合格。声音可使用系统声音并试听；绑定、试听与用户 Chat 交付分别核验，低频克隆/身份工具按实际能力使用。

运营效能从权威事实衡量：首张合格素材时间、创作交接及交接到上线时间、采用/变体采用比例、单张采用的真实 provider 成本、发布校验失败率及操作次数。先建立受控基线，再分风格/路线制定目标；不把生成张数或旧批准率当成功。界面分离、模型资格、完整生成与公开发布仍需同 revision 操作证据，不由手册或自动测试认证。
