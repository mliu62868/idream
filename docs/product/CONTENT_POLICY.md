# 内容与安全政策（Content Policy）

更新日期：2026-10-04
目标产品：全面对标 OurDream.ai 的 18+ AI 角色扮演 / AI 伴侣平台

## 0. 权威与现行边界

本文维护产品内容规则、拒绝/申诉和成年边界，是版本化 Safety Center 政策的母本。已发布本地政策版本才构成公开承诺；源文件和路由存在不等于发布。安全机制见 [安全架构](../architecture/07-security-and-compliance.md)，真实覆盖见 [当前覆盖](CURRENT_FUNCTIONAL_COVERAGE.md)。

- `MODERATION_PROVIDER=mock` 固定，`safety-gateway` 保留但不启用；保留 `underage/minor/csam` 与角色 `age >= 18`，不得关闭，也不列为 provider 更换任务。
- 日常角色/图片通过基础自动检查后准备并显式发布，无人工评分、逐图批准或公审关卡。举报、申诉和违规处置分别保留。
- 产品规则不等于 mock 能识别全部类别。机器码以 Main/Shared/provider 契约为准，当前包括 `age_under_18`、`potential_underage_content`；本文不创造第二套 API 枚举。
- 用户知道被拒动作、原因、原内容状态与可用下一步；运营的限制/恢复必须与领域回执、验证和审计一致，关闭 Case 不替代处置。
- 年龄核验与分辖区义务由适用配置和独立合规/法务确认。涉未成年素材的自动深检、证据及法定上报由该独立职责处理，不据本文启动未启用流水线；本文不是法律意见。

## 1. 禁止内容清单（硬策略，不可关闭）

**政策命中即拦截并保留必要证据，公开与私聊均适用。** 无“创作自由”或虚构豁免；下列是产品分类，不宣称全部自动检测。

| 类别 | 用户可读定义 |
| --- | --- |
| 未成年 | 任何描绘、暗示或编码为未满 18 岁个体的性 / 暗示 / 浪漫内容；含校园设定、"快满 18""很嫩"、loli 画风、童体比例（无论标注年龄）。命中即拦截。 |
| 真人深度伪造 | 用真实人物面孔 / 影像合成的内容，无论是否点名。 |
| 真实人物肖像 | 是、描绘或可被合理观者认出的真实个体（名人、公众人物、私人；在世或离世不足 100 年）；触发条件三选一：可识别样貌、姓名、指向特定个体的生平细节。 |
| 受版权 IP | 来自受版权作品的具名角色 / 世界观 / 剧情线（如"你是 Naruto"）；风格 / 流派 / 通用原型不算。 |
| 非自愿框架 | 把用户设定为非自愿施害方，或将"行为本身"呈现为卖点的场景（奴役、绑架、下药、洗脑、买卖人口、"它别无选择"）。 |
| 违法内容 | 在明显虚构框架之外描绘或教唆真实世界犯罪（武器制造、毒品合成、金融诈骗）。 |
| 规避尝试 | 用非英语 / 编码 / base64 / 变体命名 / 恶意重复重交，把上述任一类别藏起来；判定为"底层违规 + 一条独立 AUP 违规"。 |

补充硬类别，同样不可关闭：

- **乱伦 / 家庭关系**：性 / 浪漫语境下暗示血缘关系（"女儿""双胞胎"；同款多角色默认血缘除非显式声明）。
- **兽交**：与非拟人化动物的性内容（拟人角色在 AUP 内允许）。
- **粪 / 呕 / 食人（vore）**：含委婉语（"巧克力"）；vore 作为性癖无论框架一律禁止。
- **极端血腥暴力**：图 / 视频中无叙事必要的肢解、酷刑、严重伤害。文字叙事中服务剧情的风格化暴力允许。
- **恐怖主义 / 暴力极端主义**：宣扬、教唆、招募、美化。
- **自杀 / 严重自残推广**：鼓励或教唆；角色"曾经历过"的虚构承认不算。
- **进食障碍推广**："pro-ana""pro-mia"等。
- **仇恨内容**：把仇恨当人格 / 指令；基于贬低性刻板印象的种族化内容（探讨身份认同 ≠ 种族主义）。
- **宗教人物**：涉及 Jesus / Allah / Mohammed 的性 / 浪漫内容（泛宗教设定、神职原型允许）。
- **极端政治意识形态**：主要目的是鼓吹特定政治立场的角色。

> **非自愿的边界（产品关键）**：用户**从被动方**进入（被俘、被追、被支配）是**允许**的——用户对聊天保有元同意（meta-consent），可随时离开 / 改向 / 结束。禁止的是把用户设为**施害方**或把行为本身当卖点。救援弧与救援后的自愿关系允许。

## 2. 边界判断与内容质量

这些规则用于合法修改及举报/申诉复核，不新增置信度分类器或日常人审队列。

| 情形 | 产品判断 |
| --- | --- |
| petite 等体型用语 | 单独不硬拦；与未成年线索叠加按未成年禁类处理 |
| 公开头像/简介露骨度 | 公开内容标准严于私聊；受限情形有明确理由和修改路径 |
| 模糊 IP / 戏仿 | 通用风格允许，具体人物/IP 或存疑侵权按规则与个案处置 |
| 权力不对等 / dubcon | 用户作为被动方有元同意时允许；不得把非自愿施害本身作为卖点 |
| 高拒率、批量或结构相似 | 行为本身不构成内容违规；可提高举报/异常复核优先级 |

公开内容质量目标：简介 ≥200 字符、场景 ≥1,000 字符。字段质量、内容违规与发布资格分开；当前输入限制以 Shared/Zod 核实，不能用该目标恢复人工批准。允许合法修改后重交。

## 3. 拒绝与处置契约

基础拦截发生在受控调用/释放边界，返回实际机器码和可理解原因，保留 `moderation_events` 及原任务身份；被拦截的生成按 [经济契约](ECONOMY_AND_PRICING.md) 处理费用，不伪装成功。举报基于当前政策复核，未成年类最高优先；决定必须关联目标、政策版本、必要证据和审计。

私聊/私有生成不因普通运营权限而可浏览全文。复核仅用有来源和授权的必要证据，敏感明文再叠加逐目标 consent/Legal Hold 与每次审计，见 [后台规格](BackendFeatureSpec.md#510-adminops-control-plane)。复核独立于增长和营收，申诉由非原决策人处理。

## 4. 用户侧申诉流程（产品流，非仅 admin 队列）

### 4.1 用户怎么看到拒绝原因

- 角色提交被拒 → 创建页直接显示**拒绝原因**（映射到 §1/§2）+ 对应 policyCode + 一句"怎么改"。
- 已发布内容被移除 → 站内通知 + 原因。
- 账户被处置（警告 / 暂停 / 封禁）→ 通知 + 原因 + 申诉入口。
- 原则：**我们告诉用户发生了什么、为什么** —— 不让用户猜。

### 4.2 申诉入口、SLA、结果

| 场景 | 入口 | 复核方 | SLA |
| --- | --- | --- | --- |
| 角色被拒 | 站内"申诉"动作 → `appeals` 表；正式书面走 trust 邮箱 | **不同于**原决策人的审核员 | 内容类申诉一般 **10 个工作日**内 |
| 已发布内容被移除 | 同上 + 附原审批时间 | 同上 | 同上 |
| 账户暂停 / 封禁 | 邮件 trust 渠道（附账号 + 通知 + 具体异议） | trust 团队（非一线审核） | 复杂案件更久，会书面告知 |

以上入口与 SLA 是政策服务目标；公开镜像前必须核对真实联系方式、人员与可执行处理能力，不把未发布占位 trust 邮箱或本文表格当作已兑现承诺。重放申诉沿原决定身份，恢复必须重验目标与其他有效限制；回复用户与内部备注分开。

申诉结果三选一：

1. **维持原判** —— 给出更清晰的政策依据。
2. **推翻原判** —— 内容恢复 / 账户恢复。
3. **修改结果** —— 例如按指定修改后可重新发布。

### 4.3 不可申诉 / 非申诉路径

- **涉未成年内容永不可申诉、永不恢复、永不重交**；账户处置不可逆。涉嫌违法素材的取证/上报由合规/法务侧独立处理（不在本文件范围）。
- 对**已成文政策本身**的不满 → 走 Contact 反馈，不是申诉。
- **原样重交**（未针对拒绝原因修改）不是申诉；改了再正常重交即可。恶意近似重复重交按规避尝试处理。

## 5. 角色年龄强制（硬规则）

- **角色 `age >= 18` 硬编码强制**（创建与提交均校验）。无任何例外、无"明显虚构"豁免——*Adults, only*。
- **"Teen"等分类语义 = 18+ young adult**（年轻成年人），**绝不**指未成年或未成年外观。任何童体比例、年龄退行 / "ageing"机制、loli 画风一律按未成年禁类处理。
- 在既定 mock 配置下，**年龄字段 + `underage/minor/csam` 基础拦截必须生效**，不把更换检测 provider 作为本文件的实施任务。
- 用户侧对应：平台双向 18+ —— 角色必为成人（本节），用户必为 18+（§6）。

## 6. 分辖区年龄验证（age gate vs identity verification）

两层分开存储、分开判定（07 §2.2 / §2.3，ADR-7）：

| 层 | 是什么 | 何时触发 | 守卫 / 存储 |
| --- | --- | --- | --- |
| **Age gate（18+ 确认）** | 首访成人内容前确认"我已满 18"（接受即可，不验身份） | **所有**用户、首次访问成人内容前（AG-01） | `requireAgeGate` / `age_gate_acceptances` + cookie |
| **Identity verification（身份年龄验证）** | 第三方核验真实年龄（face/ID/信用卡），返回二值"已验 18+"信号 | **仅受限辖区** + 风险触发（AG-05） | `requireAgeVerified` / `age_verifications`（与 age gate 分表） |

身份核验是独立目标，当前不接 provider、默认 `not_required`。启用前明确适用辖区/风险、provider 和复验规则，不能凭历史国家示例自动触发。平台只接收二值年龄结果，不接收证件、自拍或活体视频。失败不授权受限功能并提供重试；有效期和风险复验进入版本化规则。
