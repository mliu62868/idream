## 2026-08-01 媒体生成权威与运营闭环

- **架构权威统一**：Main 以 `Generation Request → Attempt → TransportExecution → immutable TerminalRecord → Artifact / Delivery / Settlement` 表达一次业务请求、每次尝试、provider 调用、终态事实、产物交付与结算。Request 与精确 Attempt 在同一事务预留，派发只通过 durable Outbox；Gen 是图片/视频 provider 调用的唯一执行者。终态先写 immutable Blob record，再按 Attempt key 进入 Main-owned durable relay；Main 只负责预留、摄入、终态投影、交付与结算。Character Preview 已并入同一 Generation 链，不再保留第二套 preview transport。
- **重试与产物隔离**：每次业务 retry 创建新的 Attempt，固定 provider/profile/workflow/idempotency authority；BullMQ dedupe、terminal record 与 blob output prefix 都绑定精确 Attempt。多产物写入失败会回滚本次 Attempt 已写 blob，晚到成功不会覆盖其他 Attempt 或已完成终态，跨 Attempt 恢复只能形成可审计 shadow/reconciliation evidence。
- **终态自恢复**：terminal relay 与 finalize 的 exhausted failed rows 使用 cursor 分页、逐行 schema/Attempt/Outbox 精确校验和毒行隔离；合法 failed row 即使在 cold start、queue paused 时也是 durable carrier，进程启动后的 initial scanner 会将其安全重驱动。Gen source row 只有存在精确 Blob terminal record 才可恢复；无 Blob、身份不匹配或 invalid row 继续阻断。过期 `running` provider lease 不会仅因 source row 仍在队列而被延迟，除非已有精确 Blob/relay 终态证据，否则进入 `unknown` 运营对账。
- **运营恢复面**：Character Workspace 新增统一 Media Operations 投影，图片、视频、音频都显示当前阶段、阻塞原因、可执行 next action 与审计入口。视频 create/review 使用 durable mutation intent；`unknown` 不再直接重试，而是由 operator 选择继续观察、确认失败/退款或采纳晚到成功。审核/批准仍只改变候选事实，不等同于 Release publish 或 live Serving。

## 与旧 ProductFeatureMap 的差异

`ProductFeatureMap.md` 是目标功能地图，不再作为实现进度表；当前实现状态以本文为准。2026-06-29 已清理 creator public profile、Profile billing、语言切换器等明显旧描述。若未来 FeatureMap 和本文冲突，以本文和代码/E2E 证据为准。

当前暂不追求公开上线。未来重新进入公开上线阶段时，缺口不是这些本地产品流程，而是：

1. 真实生产 provider 从 mock 切换。
2. 生产 secrets 和公网回调 URL 配置。
3. 对每个真实 provider 跑 live probe。
4. `bun run check:launch -- --launch-env-file .tmp/production-launch.env` 全绿。

## 不应误判为缺失的点

- `sd.cpp` 不应直接出现在 main-web 或 gen worker 产品配置里；它只能作为 Pipeline gateway 后面的 runner。
- `Video` 只在 `video_gen=true`、真实 backend/profile/character recipe/pricing 与用户 entitlement 同时成立时曝光；当前 LTX 线路是单图角色 I2V，不能把 freeplay 或没有物化主图的角色误报为可生成。
- Community 在没有公开 dreamer 数据时显示空状态是正常状态；有数据时 E2E 覆盖 dreamer card 和 profile report。
- 本地 mock checkout 只证明权益/ledger/UI 闭环；现在 UI 明确标为 demo-only，不代表真实支付可上线。
