The latest payment probe evidence in this workspace is still `provider: mock` from 2026-07-04, and the production-shaped gate correctly rejects it.
- Private media storage: production object storage env and a fresh blob probe are required before generated media persistence can be treated as production-grade.
- Age verification gateway: production service URL, API key, webhook secret, public return/callback URLs, and a fresh age probe are required before public launch.
- Deployed web surfaces: `WEB_SURFACE_PROBE_REPORT` must be refreshed against the deployed main/admin origins, not only local PM2.
- Observability: production `SENTRY_DSN` is still required by the launch gate.
