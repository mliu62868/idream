# 角色视觉设计当前状态审计

审计时间：2026-07-24
范围：Admin 角色入口、视觉身份、参考集、图片线路资格、图片资产首次设置
样本角色：Alexa Reeves、Diana - The bet to date the weird girl !

## 总体判断

当前系统已经建立了较完整的视觉资产权威链，但尚未形成可用的角色一致性生产闭环。

- 治理与追溯：较强。视觉身份、参考集、线路资格、生成审核、草稿资产包和发布快照彼此分离，服务端会拒绝过期身份、参考集、线路和审核证据。
- 视觉身份质量：较弱。当前活动视觉身份的 `identityPrompt` 是剧情文案，不是可复用的人脸身份描述；结构化面部、头发、身体与标志特征基本为空。
- 运行就绪度：未完成。当前 16 个角色中只有 2 个有活动视觉身份和活动参考集，合格图片线路为 0。
- 一致性验收：部分完成。线路资格支持固定 10 个方向、40 张样本、90% 通过率和 0.9 身份均分，但当前本地生成质量证据仍把身份标为 `unscored`，实际依赖人工评分。
- 产品闭环：存在断点。视觉实验可以提交“候选身份”评审，但候选图没有明确的晋升动作进入新视觉身份或参考集。

本报告下方保留的是修复前审计快照；以下条目是当前实现与数据状态：

- 已幂等升级现有 Alexa Reeves 与 Bailey Price 数据。两者当前活动视觉身份均为 v3，旧剧情身份和中间修复版本保留为 archived 历史；新视觉身份与新 Reference Set 的快照 hash 均已验证。
- 已打通候选晋升。通过身份实验生成并完成逐项可见质量评审的候选，可由运营显式激活为新的不可变视觉身份和 Reference Set；旧身份归档、旧草稿失效，线上图片不会被自动替换。

## 流程步骤

1. 角色入口：健康度一般
   - 页面能明确显示 16 个角色都在一次性设置阶段，并推荐一个下一步。
   - 风险：没有任何角色进入图片生产、检查发布或线上运营阶段，说明当前流程不是可持续生产状态。
   - 证据：`01-character-portfolio.png`

2. 视觉身份实验：健康度较弱
   - 优点：活动基准和候选图并排比较；生成明确标注为可逆实验，不会自动修改线上资产。
   - 风险：默认“文生图”使用纯文本且每轮随机，无法承担人物身份保持；当前身份 Prompt 是剧情钩子，活动基准与候选人的脸部身份已有明显漂移。
   - 风险：提交候选只记录 `identityConsistency: unscored`，没有客观身份一致性验收。
   - 证据：`02-visual-identity-experiment.png`

3. 正式身份、参考集与线路资格：结构健康，数据未就绪
   - 优点：活动身份、锚点、参考集修订和线路资格分开显示；参考集是不可变快照。
   - 风险：Alexa 只有 1 张参考图，线路资格证据为空；系统要求先生成并审核 40 张线路测试图。
   - 风险：当前推荐的 Qwen-Edit 路线尚未形成资格记录。
   - 证据：`03-formal-visual-authority.png`

4. 图片资产生产：正确地失败关闭，但尚不可用
   - 优点：未通过视觉设置时禁止生成，不允许绕过一致性权威。
   - 风险：页面同时表达“本批次已锁定身份、参考集和生成路线”与“图片生成路线不可用”，状态文案存在语义冲突。
   - 证据：`04-image-assets-blocked.png`

5. 现有角色首次视觉设置：健康度较好
   - 优点：把现有线上肖像封存为身份参考，不改变当前线上图片和发布版本；首屏只给一个可执行动作。
   - 风险：主动作下方提示之后还有 6 个设置步骤，整体启用成本仍高，需要在首个动作完成后持续保持单步引导。
   - 证据：`05-existing-portrait-bootstrap.png`

## 服务端保障

已确认：

- 生成请求携带活动视觉身份版本、参考集修订和完整 `referenceManifest`。
- Qwen-Edit/ComfyUI 工作流有真实图片输入槽，运行时会发送参考图，而不只是拼接 Prompt。
- 采用草稿图片时要求最新审核为 approved、`identityConsistency` 为 passed，并且可见质量检查全部通过。
- 身份、参考集或线路变化后，旧候选和旧草稿资产会失效。
- Release 再次校验视觉身份 hash、参考集快照、线路资格、生成尝试和审核血缘。

仍缺少：

- 当前没有合格线路记录。
- 当前本地生成质量写入的身份状态是 `unscored / evaluator_unavailable`。
- 活动视觉身份没有有效的结构化身份特征和一致性分。
- 视觉实验候选到正式视觉身份/参考集之间没有明确晋升闭环。

## 可访问性风险

- 页面具备跳转主内容链接、区域标题、tablist、状态区域和明确按钮标签。
- 大量折叠区与状态标签需要补做键盘焦点顺序、展开状态播报、缩放重排和对比度测试；截图和 DOM 不能证明完整 WCAG 合规。

## 建议优先级

1. 修正视觉身份真源：剧情文案不得写入 `identityPrompt`，补齐结构化身份特征。
2. 用真实参考图跑通并发布至少一条 40 样本合格线路。
3. 为生成结果接入自动人脸/身份评分；人工审核作为补充，不作为唯一保障。
4. 补上“实验候选 -> 新身份版本/参考集”的显式晋升流程。
5. 清理图片资产页中“路线已锁定”和“路线不可用”的冲突文案。
